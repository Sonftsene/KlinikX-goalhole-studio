# GoalHole Studio Pro v6.1

Android source and automated APK build for GoalHole Studio Pro.

The GitHub Actions workflow builds an installable debug APK and publishes it as an artifact named `GoalHole-Studio-Pro-v6.1-APK`.

## dupcii — klinik ekip portalı

Hostinger için hazır klinik portalı `nobetmed/` klasöründedir. Kurulum: `nobetmed/KURULUM.md`. Yüklemeye hazır paket: `dist/dupcii-hostinger.zip`.
